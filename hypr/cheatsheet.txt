━━━━━━━━━━━━━━━━  KEYS · Super = Windows key · type to search  ━━━━━━━━━━━━━━━━
Super + /                  this cheat sheet
── APPS ──────────────────────────────────────────────────────────────────────
Super + Enter              terminal (Alacritty)
Super + Space              app launcher (type, Enter to open, Esc to close)
Super + B                  browser (Brave)
Super + E                  files (Dolphin)
Super + W                  wallpaper carousel (ricing repo): arrows/wheel browse, Enter apply, Esc close
── WINDOWS ───────────────────────────────────────────────────────────────────
Super + Q                  close window
Alt + Tab                  next window (brings it to the front)
Alt + Shift + Tab          previous window
Super + M                  maximize on/off (fills screen, keeps bar)
Super + F                  fullscreen on/off
Super + V                  float / tile window
Super + J                  split side-by-side / stacked
Super + P                  pseudo-tile (keep the app's own size)
Super + arrows             focus window left / right / up / down
Super + Shift + arrows     move window left / right / up / down
Super + left-drag          move window with mouse
Super + right-drag         resize window with mouse
(no minimize)              use the scratchpad or another workspace instead
── WORKSPACES ────────────────────────────────────────────────────────────────
Super + 1…9, 0             go to workspace 1–10 (created on demand; bar shows only used ones)
Super + Shift + 1…9, 0     send window to workspace 1–10
Super + scroll             next / previous workspace
3-finger swipe             next / previous workspace (touchpad)
Super + S                  show / hide scratchpad ("minimize" spot)
Super + Shift + S          send window to scratchpad
── SYSTEM ────────────────────────────────────────────────────────────────────
Super + L                  lock screen
Super + Shift + E          log out (back to login screen / Plasma)
Print                      screenshot region → ~/Pictures/Screenshots + clipboard
Shift + Print              screenshot whole screen
volume / mute / mic keys   work everywhere, even on the lock screen
brightness keys            screen brightness
play / next / prev keys    media control (Spotify, browser)
idle                       dims at 4 min · locks at 5 · screen off at 6
── BAR (Waybar) ──────────────────────────────────────────────────────────────
click workspace number     switch workspace
scroll on bar              switch workspace
click  Vol                 open audio mixer      · right-click: mute
click  clock               time ↔ date           · hover: calendar
tray icons                 Wi-Fi menu · Bluetooth: open "Bluetooth Manager" from the launcher
gear (far right)           System Settings  · right-click: audio mixer
music (left side)          shows what is playing · click: play/pause · right-click: next
running cat                runs faster with CPU load, naps when idle · hover: CPU %
